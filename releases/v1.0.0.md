## Blobscribe 1.0.0

First GitHub distribution of Blobscribe, a free offline English dictation app
for Apple Silicon Macs running macOS 14 or later.

### Features

- Automatic text insertion into the active text box, enabled by default for new installs.
- Existing menu-bar interface, live preview, adjustable noise filtering, push-to-talk,
  always-on dictation and configurable shortcuts.
- Bundled Whisper small.en Q5_1 model; no account, API key or cloud transcription.
- Optional Clipboard mode for manual pasting.

### Installation

Download Blobscribe.dmg, open it, and drag Blobscribe into Applications. Quit the
old app before replacement. Grant Microphone access and enable Accessibility
for automatic insertion. Existing explicit output-mode preferences are kept.

The app is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks
a trusted download, attempt opening it and use System Settings → Privacy &
Security → Open Anyway if offered. Do not disable Gatekeeper globally.

Use Blobscribe.dmg.sha256 to verify the download. The DMG contains only the app
and an Applications shortcut. This is a proprietary freeware release; source
code is private. Bundled third-party libraries/model retain their own licenses.

### Validation

- Release app built on macOS 27.2.1 / Apple M5 Pro with Xcode 27.2 and Rust 1.97.1.
- 42 Rust unit tests passed; formatting and Clippy checks passed.
- Existing offline audio evaluation passed its speech/noise detection, endpoint
  and transcription thresholds. It recognized 6 of 7 speech fixtures and
  returned empty transcripts for all 3 noise fixtures. This small fixture set
  is a regression check, not a general dictation-accuracy benchmark.
- Verified arm64 architecture, macOS 14 deployment target, ad-hoc signature,
  hardened runtime, microphone entitlement and system-only dynamic linkage.
- Verified the bundled model's pinned size/SHA-256 and included application and
  third-party license notices. Source, debug symbols, logs and test recordings
  are excluded from the app.
- Verified the finished DMG's checksum, image integrity, two-item layout and
  mounted app signature/resources.
- App bundle: 194,318,302 bytes. DMG: 186,235,085 bytes (186.2 MB).

Not manually verified for this release: live Microphone/Accessibility consent,
automatic insertion into usual apps, Gatekeeper behavior on a clean Mac, other
Apple Silicon generations and macOS 14. Ad-hoc signing does not provide
notarization.
