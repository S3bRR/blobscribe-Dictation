# Changelog

## 1.0.0 — first GitHub distribution candidate

- Offline English dictation with the existing Whisper small.en Q5_1 model.
- Existing menu-bar UI, preview, noise filtering, always-on/push-to-talk and hotkeys.
- Automatic insertion enabled by default for new installs; optional Clipboard mode.
- Ad-hoc signed Apple Silicon app with hardened runtime, bundled model and licenses.
- Public binary downloads and issue tracking; application source remains private.
